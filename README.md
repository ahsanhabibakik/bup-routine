# BUP Routine Builder

Mobile-first PWA to browse the BUP BBA-General class routine (July–December 2026, all batches & sections) and build your own weekly routine with automatic clash detection and PDF export.

## Features
- **Browse** every class by batch (2023–2026 + MBA), section, day, or free-text search (course, code, teacher).
- **Build** a routine: quick-load a full batch section (e.g. BBA-2024 A) or add/remove individual classes from any batch/section.
- **Routine grid**: weekly Sun–Thu view with time-clash detection (overlapping classes outlined red), course/day counts and per-day gap analysis.
- **Download PDF**: print/save the grid.
- **PWA**: installable, works offline, saves your routine locally.

Data transcribed from the official BUP BBA-General Class Routine (v. 21.07.2026). Verify against the posted copy before enrolment.
